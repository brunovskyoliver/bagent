# Add browser panels as the only notch-window exception

bagent Browser may create one chromeless floating panel per live Browser Session. This is the only accepted exception to the product's one-panel, notch-only UI rule because an interactive, resizable webpage cannot fit the fixed notch geometry. Chat, settings, approvals, automations, and future ordinary features remain inside the existing notch panel. Expanding this exception requires a new architectural decision.
